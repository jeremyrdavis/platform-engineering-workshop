# Product Roadmap

1. [x] Workshop Agenda and Facilitation Guide — Create comprehensive facilitator guide with timing, transitions, and talking points for each session, plus detailed agenda participants receive showing all presentations and activities throughout the day. `S`

2. [ ] Platform Engineering Fundamentals Presentation — Develop core presentation introducing platform engineering principles, the flywheel effect, platform team mission, and how platforms accelerate development teams, with real-world examples relevant to OpenShift environments. `S`

3. [ ] Developer Hub (Backstage) Presentation — Build presentation explaining Backstage architecture, Red Hat Developer Hub specifics, software catalog concepts, template capabilities, and how it serves as the central developer portal for platform capabilities. `M`

4. [ ] Value Stream Alignment Presentation — Create presentation covering value stream mapping, how to connect platform work to business outcomes, prioritization frameworks, and methods for demonstrating platform ROI to leadership. `S`

5. [ ] Platform Team Structures Presentation — Develop content on organizing platform teams, the enabling team model, team topologies, interaction modes with app dev teams, and how to structure for both centralization and autonomy. `S`

6. [ ] OKR Development Workshop Activity — Design interactive exercise with facilitator instructions, templates, example OKRs, and post-it note/whiteboard methodology for participants to collaboratively create platform team objectives and key results. `M`

7. [ ] Platform Requirements Gathering Activity — Create structured exercise for identifying platform needs through cross-team discussion, including question prompts, categorization frameworks, and methods for prioritizing identified requirements. `S`

8. [ ] Internal Marketing Strategy Activity — Build collaborative brainstorming activity with frameworks for identifying communication channels, content types, cadences, and success metrics for broadcasting platform updates to developers. `S`

9. [ ] Golden Paths and Self-Service Content — Develop presentation and discussion guide covering golden path concepts, template repositories, scaffolding tools, self-service portals, and balancing standardization with developer flexibility. `M`

10. [ ] Metrics and Observability Content — Create presentation on platform metrics (DORA, SPACE framework, custom metrics), developer experience measurement, dashboards, and connecting technical metrics to business KPIs. `S`

11. [ ] Security and Compliance Content — Build content addressing shift-left security, policy-as-code, compliance automation, security golden paths, and embedding security into self-service capabilities without creating friction. `S`

12. [ ] Onboarding Excellence Content — Develop presentation and discussion topics on effective application onboarding, team onboarding processes, documentation strategies, hands-on examples, and measuring onboarding success. `S`

13. [ ] Workshop Materials Package — Assemble complete materials package including printable agenda, participant handouts, exercise templates, post-it note guides, example outputs, and take-home resources with links to further reading. `M`

14. [ ] Facilitator Training Materials — Create training guide for facilitators covering workshop objectives, facilitation techniques, how to handle difficult discussions, timing management, virtual adaptation strategies, and troubleshooting common issues. `M`

15. [ ] Post-Workshop Follow-Up Kit — Design follow-up materials including summary email template, action item tracker, OKR refinement guide, additional resources, and 30/60/90 day check-in framework to maintain momentum after the workshop. `S`

> Notes
> - Order items by workshop flow and dependencies (presentations inform activities, foundational concepts before advanced topics)
> - Each item represents a complete, standalone deliverable that could be reviewed and tested independently
> - Workshop is designed to be highly interactive with equal emphasis on presentations and collaborative exercises
> - All materials support a 1-day in-person format with flexibility for timing adjustments based on group dynamics
