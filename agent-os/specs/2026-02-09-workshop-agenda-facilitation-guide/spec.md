# Specification: Workshop Agenda and Facilitation Guide

## Goal
Create a comprehensive participant-facing agenda and detailed facilitator guide for a 1-day in-person Platform Engineering workshop delivered to Red Hat OpenShift customers, featuring movement-based interactive activities, visual collaboration techniques, and concrete deliverable-creation exercises.

## User Stories
- As a workshop facilitator, I want a detailed guide with exact timing, transition scripts, and activity instructions so that I can confidently deliver an engaging full-day workshop without missing critical steps or running out of time.
- As a workshop participant, I want a clean agenda showing session titles and times so that I understand the day's flow and can plan my energy and engagement accordingly.

## Specific Requirements

**Participant-Facing Agenda Document**
- Create 1-2 page Markdown document with clean, simple format exportable to PDF
- Include all session titles with exact start/end times (9:00 AM - 5:00 PM schedule)
- Provide brief 1-2 sentence descriptions for each presentation and activity
- Clearly mark all break times (mid-morning, lunch, mid-afternoon)
- Use simple table or list format for easy scanning
- Avoid facilitator-specific details or behind-the-scenes instructions
- Include workshop title, date placeholder, and welcome message at top
- List expected participants (technical leaders, architects, engineers from OpenShift and app dev teams)

**Facilitator Guide Document Structure**
- Create 20-30 page detailed Markdown document exportable to PDF
- Organize sequentially by time blocks matching participant agenda
- Include exact timing for each segment with buffer time allocations
- Provide transition scripts between all sessions using exact wording
- Include pre-session setup checklists for each activity
- Add troubleshooting tips for common facilitation challenges
- Create discussion prompt banks with 5-8 questions per interactive session
- Include expected outputs and success criteria for each deliverable-creation activity
- Add photo capture guidance with specific moments to document

**Workshop Schedule and Content Flow**
- Design 8-hour workshop (9:00 AM - 5:00 PM) with explicit breaks
- Front-load foundational presentation content in morning (first 90-120 minutes)
- Position Developer Hub presentation as mid-day topic (after first activity block)
- Intersperse three major deliverable-creation activities after relevant concept presentations (OKRs, Platform Requirements, Marketing Strategy)
- Include 15-minute breaks mid-morning and mid-afternoon plus 60-minute lunch
- Build 5-10 minute buffer between sessions for transitions and Q&A overflow
- Balance approximately 40% presentation time and 60% interactive activity time
- Suggest 2-3 additional workshop topics beyond core requirements to provide options

**Room Setup and Physical Environment Instructions**
- Provide detailed room configuration guidance for 10-20 participants
- Include table arrangement for small group work (groups of 4-6)
- Specify wall/window space requirements for post-it note exercises
- Detail flip chart stand positioning (minimum 2-3 stands for simultaneous group sharing)
- List projector/screen setup for presentations
- Include lighting considerations for both presentation viewing and collaborative work
- Specify space requirements for transitioning between seated and standing activities
- Add diagrams or descriptions for room layout reconfiguration during day

**Post-it Note Exercise Facilitation**
- Create step-by-step instructions for setting up wall/window-based brainstorming activities
- Include guidance for distributing post-it notes (colors, quantities per participant)
- Provide techniques for affinity mapping and idea clustering facilitation
- Detail instructions for managing participant movement from seats to walls
- Add prompts for encouraging quiet participants to engage in standing activities
- Include timing guidance (individual reflection, clustering, discussion phases)
- Specify how to capture and preserve post-it note outputs via photography
- Add troubleshooting tips for post-its falling off windows or participants dominating clustering

**Flip Chart Activity Instructions**
- Provide templates for what to pre-write on flip charts before each session
- Include guidance for distributing flip charts to breakout groups
- Detail instructions for group sharing and gallery walk format
- Specify marker distribution and color-coding strategies
- Add photo capture guidance for documenting all flip chart outputs
- Include examples of successful flip chart outputs (reference future-state vision format from IMG_1925.png)
- Provide facilitation techniques for keeping flip chart work concise and visual

**Future-State Visioning Exercise Design**
- Detail complete facilitation instructions for creative visioning activity shown in visual assets
- Provide headline format template (e.g., "DAANG! [Company] [Achievement headline]")
- Include bulleted outcome list framework covering technical, cultural, and business results
- Specify timing (15 min individual/small group brainstorming, 10 min creation, 15 min sharing)
- Add example outcomes to inspire participants (faster onboarding, true CI/CD, multiple prod pushes per day, etc.)
- Include debrief questions to connect vision to actionable next steps
- Position this exercise early in workshop to energize and motivate participants

**Three Major Deliverable-Creation Activities**
- Design complete facilitation guide for OKRs/goals development activity (objectives, key results, measurement strategies)
- Create detailed instructions for Platform Requirements gathering exercise (current pain points, desired capabilities, prioritization)
- Develop Marketing Strategy activity facilitation guide (communication channels, messaging, launch approach, stakeholder engagement)
- For each activity include materials list, timing breakdown, group formation instructions, output format templates, and sharing/synthesis approach
- Specify how each activity connects to preceding presentation content
- Include sample outputs or completed examples to guide facilitators

**Interactive Activity Formats and Techniques**
- Document mix of seated small group discussions and standing wall-based collaborative work
- Provide instructions for individual reflection periods before group activities
- Include techniques for group formation (counting off, topic-based grouping, etc.)
- Detail full group sharing formats (report-outs, gallery walks, teaching back)
- Add energizer activities or movement breaks between sessions to maintain engagement
- Specify how to manage simultaneous activities (some groups at tables, others at walls)
- Include guidance for managing time when groups work at different paces

**Physical Materials Preparation Lists**
- Create comprehensive materials checklist organized by session
- Include post-it note specifications (3x3 inch, multiple colors, quantities: 1 pad per 2 participants)
- List flip chart requirements (stands, paper pads, quantities based on breakout groups)
- Specify marker types and quantities (thick markers for flip charts, fine-tip for post-its)
- Add masking tape or painter's tape for securing flip charts to walls
- Include timer/clock for visible time management
- Specify laptop/tablet needs for capturing photos of outputs
- Add optional materials (name tents, handouts, exercise worksheets)

**Presentation Content Integration**
- Reference existing Google Slides presentations for all presentation blocks
- Specify presenter notes expectations for facilitator guide
- Include key talking points and discussion bridges between presentations and activities
- Detail demonstration approach for Developer Hub and OpenShift Dev Spaces (no hands-on labs)
- Add guidance for adjusting presentation depth based on participant technical level
- Specify Q&A management approach during presentation blocks

**Documentation and Output Capture**
- Provide specific photography guidance for all analog outputs (flip charts, post-it clusters)
- Include checklist of required photos for complete workshop documentation
- Specify how outputs will be transcribed or digitized post-workshop
- Detail participant deliverables format (each organization receives photos plus synthesized action items)
- Add guidance for real-time note-taking or scribing during discussions
- Include templates for capturing parking lot items and follow-up questions

**Out of Scope**
- Actual presentation slide deck content (exists separately as Google Slides per tech-stack.md)
- Virtual or hybrid delivery format adaptations
- Hands-on technical labs requiring laptop setup or OpenShift deployment exercises
- Post-workshop follow-up email templates or communication materials
- Participant handout templates as standalone documents (embedded in facilitator guide only)
- Workshop marketing, registration, or invitation materials
- Multi-day workshop variations or advanced follow-up sessions
- Procurement details or vendor information for physical materials
- Facilitator training videos or certification programs
- Detailed presentation scripts or slide-by-slide presenter notes
